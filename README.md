# Sanakortit

Карточки для запоминания финских слов и фраз. Тап — перевернуть, свайп вправо — помню, влево — нет.

https://labtorie.github.io/sanakortit/

Работает как обычный сайт и как Telegram Mini App. Внутри Telegram карточки хранятся в CloudStorage и видны на всех устройствах; на сайте — в localStorage браузера.

## Импорт CSV

Одна строка — одна карточка: финское слово, перевод, необязательно тип (`word` / `phrase`).
Разделитель — запятая, точка с запятой или табуляция; подходят и строки вида `kiitos — спасибо`.
Пустой перевод подтягивается автоматически через MyMemory.

```csv
finnish,translation,type
kiitos,спасибо,word
Mitä kuuluu?,Как дела?,phrase
```
